수치 해석·진료 상담 안내

체성분은 측정 조건의 영향을 받아요. 같은 기기·시간·준비 조건에서 비교하고, 한 번의 수치로 근육이나 지방의 변화를 확정하지 마세요. 측정 안내

빠르거나 의도하지 않은 체중 감소, 삼킴 곤란, 반복되는 식후 불편은 치료팀에 알려주세요. 실신이나 심한 통증이 생기면 바로 의료 도움을 받으세요. 회복 중 상담할 증상

수술 전 기준은 수술일보다 앞선 마지막 측정이에요. 수술 당일 값으로 간주하지 않아요. 장비와 측정 조건이 달라질 수 있으니 원자료를 함께 확인해 주세요.

기록

날짜·시간·장비로 구분해요. 같은 날 여러 측정도 보존해요.

공개 이력에 측정을 추가하려면 을 선택해 주세요.

현재값과 목표 비교

위전절제 후 식사 가이드

현재 먹을 수 있는 음식과 양을 기준으로 조정하세요. 수술 후 식사 단계와 개인 목표는 치료팀 안내를 따릅니다.

작게 나누고, 끼니마다 단백질

큰 세 끼 대신 하루 6회 정도의 작은 식사로 나눠 보세요. 달걀·두부·생선·부드러운 살코기 등 먹기 편한 단백질 식품을 끼니마다 곁들입니다. 천천히 씹고, 편하게 먹을 수 있는 양을 기록하세요. MSK · E01

식사 사이에 수분 챙기기

식사 중 한꺼번에 많이 마시기보다 식사 사이에 나눠 마십니다. 국·스프·단백질 음료도 수분에 포함돼요. MSK는 주로 식전·후 1시간, NIDDK의 덤핑 안내는 식후 최소 30분을 제시합니다. 개인 간격은 치료팀과 정하고, 물을 지나치게 줄이지 마세요. E01 E02

체중보다 섭취와 컨디션도 함께

체중 감소를 목표로 삼기 전에 충분히 먹고 있는지 확인하세요. 의도하지 않은 감소가 이어지거나 먹기 어렵다면 영양 상담이 필요합니다. 열량·단백질 목표는 검사와 섭취 상태를 보고 정합니다. CUH · E03 NHS · E04

당류·유제품은 식후 반응 확인

단 음료나 과자 뒤에 불편함이 생기면 먹은 양과 증상 시작 시간을 기록하세요. 덤핑증후군의 식사 조정은 진료와 함께 진행합니다. 유제품도 불편한 경우 대체 식품을 찾되, 모든 음식을 일괄 제한하지 마세요. NIDDK · E02

B12와 영양 검사 일정 확인

위전절제 후에는 B12 보충과 장기 추적을 치료팀과 확인해야 합니다. 보충 경로·용량·간격은 진료 계획에 따르고, 철분·칼슘·비타민 D 등도 확인하세요. CUH · E03

운동과 상담이 필요한 증상

운동 재개와 강도는 개인 상태에 맞춰 확인하세요. 빠른 체중 감소, 음식이 걸리는 느낌, 식후 어지럼·메스꺼움, 지속되는 속쓰림은 치료팀에 알리세요. NHS · E04

진료 때 확인할 내용

급격하거나 의도하지 않은 체중 변화, 먹기 어려운 음식, 식후 증상, 보충제·약물 목록, B12 보충 방법과 추적 검사 일정을 치료팀과 확인하세요. 실신·심한 통증 등 급성 증상은 기록만 남기고 기다리지 말고 즉시 의료 도움을 받으세요.

약물 기록은 진료를 위한 메모로만 사용합니다. 투여량·주기·중단 여부나 식단을 약물명에 따라 자동 조정하지 않습니다. 호르몬 치료 지침의 적용 대상과 한계는 E09에서 확인할 수 있습니다.

저장과 공유

기존 측정 이력과 수술일은 HTML에 포함돼 있어요. 새로 추가한 기록은 브라우저 저장·파일 백업·HTML 내보내기로 보관해 주세요.

공개 이력 파일

공개 HTML

현재 측정 이력과 수술일을 담아 내려받아요. 추가 측정 후 이 파일을 GitHub Pages에 다시 올리면 공개 이력이 갱신돼요.

파일에 포함되는 내용

공개에 동의한 인바디 측정값·측정 일시·장비·수술일이 포함돼요. 식사·운동·목표·진료·약물 메모는 포함하지 않아요.

화면 캡처·PDF 공유

공개 이력에도 건강 정보가 포함돼요. 추가한 진료 메모를 화면으로 공유할 때는 별도로 확인해 주세요.

개인 기록 저장

개인 기록을 입력하려면 ‘내 기록’을 선택하세요.

임시 보관

기록을 서버로 보내지 않아요. 기기나 브라우저 사이에 자동 동기화되지 않아요.

파일 백업·복원

12자 이상의 암호로 체성분·섭취·목표·진료 메모를 함께 보관해요. 암호를 잊으면 복구할 수 없어요.

개인 데이터 삭제

이 탭과 브라우저 저장본을 삭제해요. 다운로드한 백업이나 이미 공개한 파일은 별도로 삭제해 주세요.

진료 메모

개인 진료·복약 메모예요. 측정 이력 공개 HTML과 CSV에는 들어가지 않아요.

이름·주민번호·연락처 입력란은 없습니다.

보관 시 주의할 점

잠금을 풀면 화면에 기록이 보여요. 공유 기기나 화면 공유 중에는 주의해 주세요. 원본 측정 이력은 이미 HTML 안에 있어요. 암호화는 추가 기록과 진료 메모의 로컬 저장에 적용돼요.
