# 위로그

위전절제 후 체성분과 식사 기록을 위한 개인 웹 대시보드입니다.

- 대시보드: https://moonbio23.github.io/weelog/
- 과제용 대시보드 주소: https://moonbio23.github.io/weelog/dashboard.html
- 단일 그래프: https://moonbio23.github.io/weelog/chart.html

## 데이터와 기능

본인이 제공하고 공개에 동의한 인바디 27회 측정(2021-08-23~2026-10-13)과 위전절제일(2025-11-14)을 포함합니다. 원본 45항목을 유지하며 체중·골격근량·체지방량·기기 체지방률을 조회합니다. 수술 전 비교 기준은 2025-11-10 측정입니다.

기간·장비 필터, 인바디 직접 입력·CSV 가져오기, 날짜별 식사·수분·증상·근력·러닝 기록, 식사 시간표 편집, 월간 캘린더·CSV·진료 요약을 지원합니다. 근력 계획은 사용자 선택인 주 3일입니다. 개인 일지는 첫 저장부터 12자 이상 암호로 브라우저에 암호화 보관합니다. 새 입력은 해당 브라우저에 반영됩니다. 공개 이력을 갱신하려면 앱에서 내려받은 HTML을 저장소의 index.html과 dashboard.html로 교체합니다.

별도 식사·운동·목표·진료·복약 메모는 공개 HTML에 포함하지 않습니다. 기존 공개 측정값은 HTML 안에 들어 있습니다.

## 실행

별도 설치 없이 index.html을 브라우저에서 열 수 있습니다. 외부 스크립트 없이 동작합니다. 직접 입력과 로컬 운동 정리는 API 키 없이 사용할 수 있습니다. 선택 기능인 Gemini 운동명 정리만 사용자가 확인한 일반 운동명을 Google API에 전송합니다. 날짜·몸 상태·식사·치료·중량·횟수·메모는 전송하지 않으며 키는 탭 메모리에만 보관합니다. 무료 API에는 민감정보를 보내지 않도록 제한했습니다. 실제 API 연결은 키를 입력한 뒤 확인해야 합니다. GitHub Pages는 main 브랜치의 루트에서 게시합니다.

## 참고와 제작

식사 안내는 MSK·CUH·NIDDK·NHS, 측정과 운동 안내는 화면의 참고 자료에 출처와 적용 범위를 표시했습니다. 의료진과의 상담을 돕는 기록용·교육용 도구이며 개인 진단이나 치료 처방을 제공하지 않습니다.

Gemini로 만든 초기 대시보드를 참고한 뒤, ChatGPT 대화와 Codex로 실제 CSV 처리·화면·기능·문구를 재구성했습니다.
